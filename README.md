# React Calculator 🧮

## About the Project

This is a simple calculator application built using React.js and Vite.  
The project demonstrates the use of React components, JSX, and CSS styling to create a functional and user-friendly calculator interface.

## Features

- Basic arithmetic operations
- Clean and simple user interface
- React component-based development
- Fast and efficient build using Vite

## Technologies Used

- React.js
- Vite
- JavaScript
- CSS

## Project Structure
src/
- main.jsx
- calculator.jsx
- calculator.css

## How to Run the Project

1. Clone the repository
2. Install dependencies 
3. Start the development server
   
## Learning Outcomes

- Learned how to build a React application using Vite
- Understanding of JSX and React components
- Improved knowledge of CSS styling and UI design
